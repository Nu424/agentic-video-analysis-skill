解析の目的: {{OBJECTIVE}}

あなたは動画の特定範囲を高密度に並べたフレームタイル画像を観察し、この範囲で確認できる事実を確定します。
（タイル画像の読み方・セルラベルの意味は末尾の補足に従うこと）

やること:
- 重要な出来事ごとに、開始・終了の推定秒、根拠、確信度を整理する
- 事前の仮説（末尾に付く場合がある）を映像上の根拠で確認・反証し、`hypothesis_verdict` に答える。
  仮説なしなら `"n/a"`。仮説に引きずられず、見えている事実を優先する

判断方針:
- 見えていない出来事は補完しない。固有名称・アイテム名は、セル上で確認できた場合だけ書く
- 開始・終了の断定は、あるフレームで実際に確認できた時刻までしかできない。
  `start_bounds` / `end_bounds` に「直前フレームの時刻（未発生／継続中）」と「変化を確認したフレームの時刻」を必ず入れる。
  `start_sec` / `end_sec` はその区間内の最良推定値とする
- 開始・終了がタイル端にかかる場合は `confidence: low` にする
- 複数タイルにまたがる出来事は1件にまとめる
- 文字・UI・小さなオブジェクトが判読できない時刻は `zoom_targets` に秒数で挙げる（高解像度確認の入力になる）

出力形式:
- 下記スキーマに従い、コードフェンス付きJSON（```json ... ```）**のみ**を出力する。前後に文章を付けない。
- `confidence` は `high` / `medium` / `low`。`hypothesis_verdict` は `confirmed` / `partially` / `rejected` / `n/a`。

```json
{
  "events": [
    {
      "start_sec": 39.0,
      "end_sec": 44.2,
      "start_bounds": [38.8, 39.0],
      "end_bounds": [44.2, 44.4],
      "title": "短いタイトル",
      "summary": "何が起きたか",
      "visual": ["F5 t=39.0s: 画面に◯◯"],
      "confidence": "high",
      "zoom_targets": [39.4]
    }
  ],
  "hypothesis_verdict": "confirmed",
  "notes": "誤認しやすい点など"
}
```
