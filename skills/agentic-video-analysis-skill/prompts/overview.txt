解析の目的: {{OBJECTIVE}}

あなたは動画から作られたフレームタイル画像を観察し、上記の目的に沿った「見どころ候補」を列挙します。
（タイル画像の読み方・セルラベルの意味は末尾の補足に従うこと）

やること:
1. 動画全体の概要を2〜4文でまとめる
2. 目的に沿った見どころ候補を、取りこぼしを避けて多めに列挙する
3. 各候補について、開始・終了の推定秒とその根拠、追加確認すべき理由を書く

判断方針:
- 偽陽性は許容する。偽陰性（見落とし）は避ける。候補は広め・多めでよい
- 映像上で確認できない内容は補完しない。固有名称・細部は、セル上で読み取れたものだけ書く
- 開始・終了の断定は、あるフレームで実際に確認できた時刻までしかできない。
  `start_bounds` には「直前フレームの時刻（その時点では未発生）」と「発生を確認したフレームの時刻」を、
  `end_bounds` には「まだ継続していた最後の時刻」と「終了を確認した時刻」を必ず入れる。
  `start_sec` / `end_sec` はその区間内の最良推定値とする。

出力形式:
- 下記スキーマに従い、コードフェンス付きJSON（```json ... ```）**のみ**を出力する。前後に文章を付けない。
- `priority` は `high` / `medium` / `low`。`needs_followup` は true / false。

```json
{
  "summary": "動画全体の概要(2〜4文)",
  "candidates": [
    {
      "label": "candidate_a",
      "start_sec": 38.0,
      "end_sec": 46.0,
      "start_bounds": [36.0, 38.0],
      "end_bounds": [44.0, 46.0],
      "title": "短いタイトル",
      "evidence": ["F19 t=38.0s に◯◯が見える"],
      "priority": "high",
      "needs_followup": true,
      "reason": "追加確認すべき理由"
    }
  ]
}
```
