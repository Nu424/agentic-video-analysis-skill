解析の目的: {{OBJECTIVE}}

あなたは動画から作られたフレームタイル画像を観察し、上記の目的に沿って
後段で詳細解析すべき「候補範囲」を列挙します。
（タイル画像の読み方・セルラベルの意味は末尾の補足に従うこと）

やること:
1. 動画全体の概要を2〜4文でまとめる
2. **動画の全区間をカバーする**ように候補範囲を割る。1範囲は4〜8秒程度
3. 各候補について、開始・終了の推定秒とその根拠、次段で確認すべき理由を書く

判断方針:
- **空白の時間帯を残さない。** 目立った変化が無さそうな区間も `priority` を `low` にして必ず候補に含める。
  カバーしなかった区間は後段で一切見られない
- 偽陰性（見落とし）を避ける。偽陽性は許容する。迷ったら候補に入れる
- 1範囲を長くしすぎない。8秒を超えそうなら分割する
- 映像上で確認できない内容は補完しない。固有名称・細部は、セル上で読み取れたものだけ書く
- `reason` には「その範囲で何かが起きていそうだと判断した映像上の理由」を書く。
  これは次段の詳細解析に**仮説として渡され**、映像上の根拠で確認・反証される
- 秒数は動画全体の絶対秒（セルラベルの `t=<秒>s`）で書く
- 開始・終了の断定は、あるフレームで実際に確認できた時刻までしかできない。
  `start_bounds` には「直前フレームの時刻（その時点では未発生）」と「発生を確認したフレームの時刻」を、
  `end_bounds` には「まだ継続していた最後の時刻」と「終了を確認した時刻」を必ず入れる。
  `start_sec` / `end_sec` はその区間内の最良推定値とする

出力形式:
- 下記スキーマに従い、コードフェンス付きJSON（```json ... ```）**のみ**を出力する。前後に文章を付けない。
- `priority` は `high` / `medium` / `low`。`needs_followup` は true / false。
