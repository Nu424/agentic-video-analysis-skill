解析の目的: {{OBJECTIVE}}

あなたは特定時刻のフレームを**フル解像度**で観察し、細部（文字・UI・小さなオブジェクト）を判読します。
各画像は1枚=1時刻で、下部に `F<番号> t=<秒>s` のラベルが付いています。`<秒>` は動画内の絶対時刻です。

やること:
- 各フレームについて、画面上で判読できた文字列・UI・細部を書き出す
- 判読を試みたが読めなかった要素は `unreadable` に残す

判断方針:
- **読めないものを推測で補完しない**。曖昧なものは断定せず unreadable に入れる
- 見えている範囲の事実だけを書く

出力形式:
- 下記スキーマに従い、コードフェンス付きJSON（```json ... ```）**のみ**を出力する。前後に文章を付けない。

```json
{
  "frames": [
    {
      "timestamp_sec": 38.5,
      "readable_text": ["画面上で判読できた文字列"],
      "details": "細部の観察",
      "unreadable": ["判読を試みたが読めなかった要素"]
    }
  ]
}
```
